HSE Plan Maker writes the Oxypro Project Health, Safety & Environment Plan for a project, from the
company sample "Project HSE Plan" (Rev 00, 26.06.2024), in the same format as the Project Quality Plan
(Oxypro header, cover with photo and signature block, table of contents, "Page X of Y" footer).
You get an editable Word file (.docx) and a PDF.


WHAT IS IN THIS FOLDER
  HSE Plan Maker.html      The app. Double-click it to open it in your browser (Edge or Chrome).
                           It works with no internet.
  README.txt               This guide.
  Icon\                    The app icon (HSE Plan Maker.ico) for a desktop shortcut.
  Samples\                 Sample HSE Plans (Word and PDF) and your exports, if you choose this folder.
  00. HSE Templates\       The company samples the app is built on.


OPENING THE APP
  - Double-click "HSE Plan Maker.html". Edge or Chrome is best: they can save exports straight into a
    folder you choose and can print and share directly.
  - Desktop shortcut: right-click HSE Plan Maker.html > Send to > Desktop (create shortcut). To give it
    the icon: right-click the shortcut > Properties > Change Icon > Browse > Icon\HSE Plan Maker.ico.


MAKING AN HSE PLAN
  1. My HSE Plans lists every plan on this computer with Preview, Word and PDF buttons.
     Click New plan, or Import project to fill the project details from:
       - the Oxypro Project Library: the file saved under "PQP details and file" (.pqp.json), or the
         "Open in PQP Maker" link pasted into the Import window;
       - a PQP Maker project (.pqp), so the HSE Plan uses the same details as the PQP;
       - the Excel "Oxypro - Projects Master List" (pick the project from the list).
  2. Fill in the groups on the left, 1. Project Information to 7. Appendices. A red number shows how
     many entries are still empty or need fixing. Fields marked * are required.
  3. 3. Document Control: type the Document No., Revision and Date in the cover boxes to finalise the
     document. Left empty, they print as blank boxes for filling in by hand.
  4. 5. HSE Requirements: the code of practice for the table of contents (Dubai Code of Construction
     Safety Practice 2008, Abu Dhabi OSHAD-SF, another code or none) and the standard lists (legislation,
     SWPs, HSE Standards, competence certificates, permits, objectives and targets). Reset brings back
     the standard list.
  5. 6. HSE Policy Statements: the four signed Oxypro policies are built in. Add a newer scan to replace
     one, or untick it.
  6. Plan Sections: untick any section you do not need; the sections after it are renumbered.
  7. Review shows what still needs fixing and a preview of every page.
  8. Word, PDF, Print or Share (toolbar, summary panel, Review, or My HSE Plans).

  Exports are named <Document No.> Rev NN - HSE Plan - <Project>.docx / .pdf, for example
  OPEM-DXB-101-HS-PLN-001 Rev 00 - HSE Plan - Sample Residential Tower (G+20).pdf
  When Word opens the file it asks to update fields: choose Yes so the table of contents shows Word's
  page numbers.


SHARING
  - Email with the PDF attached: Share > Share... opens the Windows / iPhone share sheet (Outlook, Mail,
    Teams...). Share > Outlook email draft saves an email file with the PDF already attached: open it
    and Outlook shows a new email ready to address and send. Share > Email app saves the PDF and opens
    a new email in your email program; attach the PDF.
  - Link: works once the web version is published (see About this app).


SAVING AND OPENING
  - Every plan is saved automatically in the browser about a second after each change.
  - Save writes a plan file (.hsep) named <Project code> - <Project> - HSE Plan - Rev NN.hsep.
    Save as keeps each revision in its own file. Open brings a plan file back.
  - Browser storage can be cleared, so keep the .hsep files with the project records.


YOUR DATA
  Everything stays on this computer. There is no login and nothing is uploaded.
